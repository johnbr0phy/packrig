# Scratch

One-off scripts from agent sessions. They are kept because a probe that
found a real bug is cheaper to re-run than to reinvent.

They are not part of the product. Paths that used to be `tools/_rand.mjs`
are now `tools/scratch/_rand.mjs`.

If you write a new throwaway, put it here. If it earns a real name, move
it up a directory and give it one.
